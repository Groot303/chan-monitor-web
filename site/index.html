说明

评分(0–10)

分数 = 基础分 + 背驰 + 共振 + 确认 + 新鲜度 + 中枢质量,截断到 0–10。由人工设定权重的透明启发式规则计算,未经回测或校准,不是胜率或概率。

  • 高分 ≥ 5.0
  • 中分 2.5 – 4.9
  • 低分 < 2.5(过期信号通常落在此区间)

三买/二买的理论上限约 7.5,一买/一卖约 9.5,不同类型分数仅可粗略比较。

两类信号

缠论买卖点 为一/二/三类买点与卖点(背驰、中枢离开等)。

中枢上沿卖 / 中枢下沿买 为价格接近或触及中枢 ZG/ZD 的启发式提示,不是经典缠论买卖点;样式与分数规则单独区分。

配色约定

默认采用中文用户习惯:红色 = 买点,绿色 = 卖点。可点击右上角按钮切换为美股习惯(绿买红卖),偏好会保存在本地浏览器。

确认状态

未确认 表示最后一段尚未被特征序列分型确认,信号可能重绘或消失。已确认 表示所在线段已确认。

数据

行情来自 Alpaca(IEX 免费版,单交易所数据),价格未复权。信号时间为极值K线时间(美东时间),确认会滞后若干根K线。周线最后一根为当周未完成K线。
