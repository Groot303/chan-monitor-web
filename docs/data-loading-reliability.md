# 数据加载故障排查与请求恢复

2026-11-04用户反馈网站数据无法显示。本次读查时，入口和美股信号、A股研究、接力及策略接口均返回200；A股快照接收时间持续推进。通过保留TLS验证的本地只读代理，将线上实际HTML、静态资源及API响应交给手机尺寸Chromium复现，各公开栏目及A股直接重载均可渲染，没有页面脚本异常。因此未复现本次用户端故障，不将某个数据源、服务器停机或用户网络当成已确认根因。

代码检查发现可独立复现的前端缺陷：fetch及response.json没有截止时间。如果请求头或响应体持续不结束，A股研究、接力和策略的busy标志无法在finally释放，后续刷新/定时更新被跳过；美股信号则可能一直显示加载骨架。旧美股信号页从后台恢复或网络重新连通也不会主动重新读取。这些是本次修复范围，不声称已经证明用户当时一定遇到了其中之一。

修复内容：

- 在既有app.js中定义共享只读JSON读取器，不增加额外启动脚本依赖。15秒包含请求与响应体读取，超时尝试AbortController取消，同时独立结算Promise；即使底层忽略取消也能解锁，迟到结果不能成功返回覆盖界面。
- 美股信号、宏观、A股研究、接力与策略观察页使用相同截止机制，保留no-store及HTTP错误处理。读取器不发送POST，不调用交易或后台执行接口。
- 信号、首次策略及宏观读取失败有明确重试入口；已有A股、接力与策略快照保留且标明过期/连接中断，不补零、示例行情或静态旧数据。
- 美股信号在页面重新可见或online事件时重读；其他观察页在网络恢复时可重新读取。原有日期/市场/版本代次保护保留，旧请求不能覆盖新选择。

15秒是交互超时，不是市场数据延迟保证。初始HTML或JavaScript文件本身无法到达、用户侧DNS/网络路径、缓存/扩展及仅发生在特定设备的问题，仍需对应错误或复现场景定位，不能由服务端当前200响应排除。成交规则、策略权重、自动执行、密钥、VPS配置及账本均不修改。

验证：`node tests/test_data_loading_ui.cjs`。包含忽略取消的挂起请求、挂起响应体、迟到响应、正常请求清理定时器、HTTP错误，以及真实页面各数据读取器的超时/重试、旧快照保留、online/可见恢复。API为明确测试夹具，浏览器没有写入请求。既有移动交互、Apple交互、策略、A股研究、接力回归仍执行。
