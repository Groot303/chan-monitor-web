# 手机优先的研究手记排版

保留信号、标的总览、持仓、大环境、说明五个业务页面；沿用原来的信号、持仓、宏观、图表、术语和公司资料接口。只调整呈现、筛选入口和详情阅读顺序。

## 变更

- 手机采用原有底部五项导航，信号以带分隔线的列表展示，保留分数、类型、周期、状态、价格、时间、距今和共振。
- 标题使用本地宋体衬线，正文使用系统黑体；深色炭墨 / 浅色纸白主题共用酸橙色操作强调。
- 小屏筛选使用底部面板，实时显示结果数量；支持遮罩、Esc、焦点约束及关闭后返回入口。
- 统一最低分数控制到筛选栏；设置面板保留术语偏好和配色说明。原筛选状态仍保存在 localStorage。
- 增加已有5分钟数据的筛选选项，将 PRE_* 显示为对应中文预警名称。
- 详情为手机全屏：关键价格、未确认风险、图表、折叠评分依据、多周期状态及原有全部信号/静态对照图入口。
- 持仓及大环境不再重复显示信号KPI；各页面的数据状态使用对应接口的时间和错误状态。
- 图表增加请求版本校验，避免快速切换时旧请求覆盖新图。

## 10项设计验收

| 标准 | 对应实现 / 可检查位置 |
|---|---|
| 真实感 | 原有底部导航、成熟的底部筛选和明细列表；模式参照Yahoo Finance、Airbnb、IBKR、FRED，不声称复刻素材站或获得奖项 |
| 视觉亮点 | 炭墨/纸白、酸橙强调、编辑式宋体标题与侧排期号 |
| 克制 | 移除信号卡片的装饰圆环，字段按阅读顺序排布；设计解释留在文档 |
| 流程完整 | 筛选→结果→详情→返回，持仓/宏观/术语入口保留；本工具不增加注册、支付 |
| 深色质感 | 背景、表面、控件三级；文字与状态颜色独立；浅色单独调校 |
| 微交互 | 行按压、详情箭头位移、筛选计数及面板过渡；尊重减少动态设置 |
| 转化结构 | 首次引导说明用途、来源与方法，再进入筛选/核验；不虚构评价或强加营销落地页 |
| 字体排版 | 宋体标题、黑体正文、等宽数字；至少五级字号与400/500/600字重 |
| 手机优先 | 底部导航、底部筛选、全屏详情；320–1440px宽度回归，侧排期号不影响内容 |
| 新鲜度 | 以排版、细线、留白建立层级，无紫蓝渐变、毛玻璃和圆环堆砌 |
