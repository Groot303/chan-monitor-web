# A股连板研究工作台

## 范围与入口

A股专门研究连续涨停。手机底部六个栏目：题材、梯队、炸板、接力、昨日、关注。桌面使用同样任务结构。可按名称、六位代码、行业及概念搜索，查看来源首封/末封、封单、行业、当日涨停归因与网站实际观察时间。关注清单只存浏览器本地，不跨设备同步，不自动继承旧策略自选股。

梯队以“主要题材 → 实际连板数 → 股票”展开，例如机器人下分别列出首板、二板、三板的名称与代码。可选择单个题材，并与板数和搜索条件组合筛选；五板以上仍按六板、七板等实际高度显示。仅纳入当前已采集且状态为封板的股票，未核验题材单列，不按其他概念重复计数。筛选后没有结果只表示未采集到符合条件的标的，不声称全市场该题材没有股票。

原A股缠论信号、图表入口、分析任务和Telegram通知退出运行链路。run_cn.py等文件只作为离线遗留资料，不能再据此判断网站采用原策略。旧信号/图表URL返回410。美股分析、通知、自动模拟账本不变；API改为调用仓库内流水线脚本，确保使用已停用A股分析的版本。VPS部署脚本、IBKR和密钥机制未改。

新增[题材接力观察](cn-theme-relay.md)，基于实际分钟快照比较集中开板后的5/15/30分钟题材封板变化，只描述已核验样本的先后变化，不证明资金流向。

## 来源与数据契约

`GET /api/cn/research`返回`cn-limitup-research-v1`，可选`?date=YYYY-MM-DD`。只读取数据库，不触发采集、通知或交易，`Cache-Control: no-store`；POST不支持。日期选择只展示真实已采集记录，不从今日响应构造历史行情。

| 数据 | 来源 | 验证及边界 |
| --- | --- | --- |
| 涨停/炸板/昨日表现/跌停池 | 东财公开观察池 | 验证rc、qdate、总数、重复代码、有限价格及连板高度；列表不完整单列partial |
| 当日涨停题材归因 | 开盘啦DailyLimitPerformance | 分首板至五板以上池请求；仅提取经检查的代码、名称、事件日期、主要题材、其他概念及题材ID；与东财名称对应 |
| 行业 | 东财hybk | 单独保留，不当作当日涨停原因 |
| 网站观察事件 | SQLite实际采样 | 首次观察、开板、回封来自实际状态变化，不借用来源首封时间 |

没有Token、用户ID、设备ID或新增API密钥。使用标准TLS与环境代理，公开接口可能失效、限流或改变字段；可访问不等于具有稳定性、低延迟或再分发保证。正式商业化前需确认来源许可与SLA。

东财价格p/1000，封单为fund，昨日连板高度为ylbc；不把fund解释为主力流入，不以固定10%推算全部股票涨停价。开盘啦其他数字字段未经验证不作价格或连板高度使用。发现归因冲突或事件日期不符时不关联。另一个开盘啦板块接口实测曾返回昨日Date，即使Time为今日也未使用。

`observed_at`为服务器收到并完成本轮快照的时间；各来源保留请求及接收时间。`first_observed_at`只来自网站真实日志。来源首封、末封、source_event_time分别显示，不冒充首次发现或可交易时间。`exact_event_time`始终未知；分钟采样之间的开合可能遗漏，无法证明涨停排队成交、撤单或逐笔完整性。

状态为current、closed、partial、stale、historical、unavailable。current只表示交易日匹配且采集较新，不证明交易所实时性。缺失池和未核验统计为null/“—”，真实空池才为零。两池日期有效、列表完整、不交叠且接收时间相差不超过30秒，才记录观察变化和计算快照开板占比。该占比不是全日炸板率。

### 题材炸板统计修复（归因契约2）

2026-10-30发现：11:29快照东财炸板池有14只，但开盘啦DailyLimitPerformance仅返回当前封板股归因，14只炸板均未归类。旧页面把各题材“已匹配0只”展示为“0炸板”，属于错误的完整性暗示，并非当日没有炸板。

现在同时返回attributed_broken、broken_attribution_total、unattributed_broken和broken_attribution_complete。任一炸板归因缺失或两池状态不一致时，各题材broken_count为null，known_broken_count仅记录已匹配下限；页面显示“炸板待补全”或“≥N炸板·待补全”。待核验组单独列出已取得的未归因数量。旧快照读取时重算覆盖率与未知标记，不补造原本没有的历史归因。

同日早先已取得的开盘啦主要归因保存在theme_memory，股票开板后可沿用，明确标记earlier_today及真实attribution_observed_at；不能跨日、使用未来证据或名称不匹配的数据，也不能用缓存遮盖当前来源的冲突。升级时只从保留的真实快照恢复归因及原接收时间，不改写历史快照。首次升级即使午休也刷新一次，随后维持原休市节奏。该修复没有接入一个未经验证的开盘啦炸板接口，不保证归因覆盖达到100%。

炸板名单仍来自东财当前炸板池；盘中开板后回封者在涨停池保留来源开板次数，不再计入当前未封住名单。东财与开盘啦的市场范围、采样时间和统计定义未证实完全一致，不宣称两者炸板数应相同。

昨日N板到今日N+1板按昨日池ylbc与当前封板池交集计算，标为盘中观察；未在当前池不等于已确认收盘断板。题材按供应商主要归因分组，不把全部概念叠加成虚假的板块强度，也不发布未经验证的龙头评分。

## 调度与持久化

独立cn_research后台任务每60秒检查，45秒防重。XSHG真实交易日历决定日期、午休和休市；日历不可用时停止采集并显示未知，不回退为工作日猜测。盘前09:15开始当日采集，可能暂时没有有效来源数据；收盘后获取末次快照，之后休市复用明确标记的记录。浏览器每30秒只读更新，刷新按钮不会请求上游。

独立库`api_data/research/cn.sqlite3`，不使用美股交易账本。原始来源及分钟快照成功采集后清理至最近7个自然日，每日最后快照保留60天；不可改写的观察事件继续保留。全源失败保留最近成功快照并标为过期；部分来源失败保留有效部分并标未知，不能以空列表覆盖成功数据。此库只从启用后积累，不能补出过去真实观察时间。
