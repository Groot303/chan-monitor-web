# 美股手动模拟练习盘 V1

依赖 P0 审计 PR #2。本分支基于 `audit/swing-p0-timing`，最初用于叠加审核；用户现已授权按依赖顺序合并 main 并上线。
这是美股手动入场、自动止损与复盘工具，不是 P1 自动候选筛选器或策略有效性证明。

按用户最新要求，后续美股与 A 股分别建设：本 PR 只推进美股，A 股保留现有页面，等待新策略单独设计。参见 [市场建设范围](market-scope.md)。

## 走通的用户路径

1. 手机底部“练习”进入独立账户；也可从美股信号/标的详情“加入美股模拟练习”携带标的。
2. 仅创建美股 USD 账户，默认初始资金 100,000，允许创建时设置 1,000—10,000,000。
3. 填数量、理由、可选止损价，并明确选择是否自动执行止损，先预览参考行情、费用和资金预留，再确认提交。
4. 订单进入待成交；服务器每60秒检查满足证据的行情，打开/刷新时也同步；之后可减仓、平仓、撤销未成交单及设置对应批次的自动止损。
5. 查看现金/持仓、含费用收益、已采样回撤、卖出胜率/盈亏比、同时间区间指数对比和资金曲线；可导出完整账本 JSON。

账户凭据只保存在创建它的浏览器本地，服务器仅存随机凭据哈希；没有跨设备登录/恢复流程。
清除浏览器数据可能失去访问权。导出记录不包含访问凭据，不能拿 JSON 导入回填交易。
真实 IBKR 持仓入口继续屏蔽，练习持仓不调用券商接口。

## 服务器与安全边界

- 新模块 `paper_trading.py`、`paper_market.py`、`paper_routes.py`；api.py 只注册独立 `/api/paper/*` 路由。
- SQLite 位于 `DATA_DIR/paper/ledger.sqlite3`，在静态站点及公开 charts 挂载之外，文件权限 0600；父目录新建时 0700。
- `PaperStore` 默认只允许 us，公网接口拒绝 A 股建账及 A 股凭据读写；不能通过改 market 参数进入其他市场。A 股模式下隐藏练习入口，旧 #paper 深链返回信号页。
- 每个账户有独立随机 Bearer 凭据，只能访问自己的模拟账户；不能用于已有 API_TOKEN 管理接口。未改现有密钥、IBKR、部署配置。
- 只有进程环境 `PAPER_TRADING_ENABLED=1` 且后台定时器运行时可用。用户授权上线后，api.service 显式启用该开关，继续沿用已有部署流程。/api/jobs 可核验启用与下一次后台检查时间。
- 若未来公网开放自助创建，需结合站点登录/账户恢复及网关限流评审。当前有创建频率/总账户数限制、单账户待成交/总订单上限、请求体大小限制，不提供多人共享同一账户的凭据分发功能。
- SQLite `BEGIN IMMEDIATE` 事务串行处理资金、股份预留和成交；幂等订单编号防止重试重复下单。相同编号不能修改原始参数。
- `events` 表禁止 UPDATE/DELETE；已有成交价不会因行情修订而重算。API 没有修改初始资金、回填/删除成交或清空历史的入口。
- 所有账户查询、订单与撤单都先同步后续行情；不能在已观察到可成交行情后反悔撤掉历史成交。
- API 响应 no-store。数据库不是实盘/券商账户，不存券商密钥。

## 成交模型 paper-v1-5bps

手动订单的时间取服务器接受时刻，客户端传入旧时间、价格和信号快照均不能覆盖它。
订单档案由服务器读取当时信号快照、regime 和 strategy_context；不将极值时间伪装为 first_seen_time。
人工操作可用于研究不同情境；不意味着 P0/P1 的环境或入场门槛已经放行。

- 只允许现有美股股票代码。纳指等指数只能作参考，不能买卖。
- 采用已有导出的 5 分钟 OHLC。美股 Alpaca/Yahoo 标签按开盘解释；用 XNYS 常规交易日历核对起止，未到收盘的 K 线不进入撮合。
- 严格晚于订单接受时刻的后续常规 5 分钟开盘才有资格（同一时间边界保守跳过）。只在该根已完成且可被当前服务器观察时追加成交事件。
- 这是声明的 K 线开盘成交模型，不是盘口/排队/成交量保证。实际确认可能延迟到刷新，填充事件同时保存模拟开盘时间与服务器实际记录时间。
- 检查整个待撮合常规时段前缀：缺少更早的预期 K 线时暂停，不挑选后面的有利价格。非交易时段正常跳过；平坦 K 线保守等待。
- 多笔待成交单按开盘时间与提交顺序撮合。若后来到达的旧行情会排到既有成交之前，拒绝该练习单并留原因，不重写现金/持仓历史。
- 固定不利滑点各 5bps，价格按分四舍五入；现金与费用按分保存。买单按参考金额加 5% 跳空缓冲预留，并在成交时复查其他订单的资金预留；不足则拒绝。
- 美股费用假设：每股 $0.005，最低 $1。这是版本化练习参数，不是现实完整券商费表。
- 整股做多，不允许卖空/超卖/杠杆。FIFO 成本包含买入费用，卖出收益扣除卖出费用。
- 自动止损须明确勾选，旧计划止损默认不启用。新买入成交根收盘后生效；跳空按开盘卖，盘中触及按后续开盘卖，不猜根内先后。详见 [自动止损模型与证据](paper-auto-stop.md)。
- 超过 7 天未观察到成交的待成交单到期，释放预留；不能用到期后才恢复的历史去重建虚假实盘证据。

### A 股暂缓建设

现有 A 股信号、图表与说明页面保留；本次未修改其策略、数据生成或通知规则。
A 股模式不展示练习页/详情下单入口，手动访问 #paper 也不会进入美股账户。
后端默认只支持 us，不接受 A 股账户创建，也拒绝旧 A 股凭据操作。
此前核心中已有的 A 股约束分支只在显式启用的隔离单元测试中保留回归，不作为产品支持或下一阶段承诺。
未来 A 股策略确定后单独设计账户/页面/数据契约，不自动沿用美股筛选或执行规则。

## 估值、收益和基准

- 持仓以最近完成且日历有效的 5 分钟收盘价估值；开市时最多容忍 30 分钟滞后，休市时以最近交易时段末为参照。日历缺失则暂停。
- 任一持仓行情缺失/陈旧，当前总净值和收益为 unknown，不当作零市值或零收益。持仓行可展示带时间的旧参考价。
- 曲线从初始资金开始，随后只追加有足够同步行情的观察点；不会拿卖出后的现金写到卖出前的旧基准时间。
- 最大回撤是已采样净值回撤，可能低估根内/刷新间隔风险；不伪造未观察到的中间净值。
- 胜率按产生已实现盈亏的卖出笔数统计，部分减仓也计一笔，盈亏比为平均盈利卖出笔数收益/平均亏损卖出笔数损失，非完整交易轮次。
- 美股参考纳指，仅比较同时具备基准与账户净值的同区间；数据不足留空，不拿不同时段收益比较。
- V1 不模拟分红、拆并股、利息、汇率、美股结算/PDT、真实盘口深度和所有税费。公司行动期间暂停解读收益，后续应引入可审计调整事件。
- 模拟收益不能证明策略有效；本次没有收益率/胜率已验证的结论。

## 复现与验证

```sh
pip install -r requirements-test.txt
python -m unittest discover -s tests -p 'test_*.py'
python -m tests.check_paper_calendar
# Node 需 playwright 和本地 Chromium
node tests/test_paper_ui.cjs
node tests/test_mobile_ui.cjs
node tests/test_apple_interactions.cjs
```

本地浏览器测试由 `tests/paper_fixture_server.py` 提供固定时间与明确测试行情，走真实路由、账户凭据、SQLite、预览、等待、后续成交、刷新恢复、减仓/撤单、导出与两主题多屏宽。
`/test/advance` 只存在于此本地测试服务，生产 api.py 不导入测试服务。
真实日历检查覆盖美股感恩节、提前收盘、A 股国庆休市及午休、周末行情新鲜度。
撮合单元测试覆盖成交时序、并发预留、幂等、缺行情、数据修订、跨订单先后、T+1、费用、权限隔离与账本不可变。

美股后续单独任务建议：站点登录/恢复、公司行动调整、定时净值采样、更多执行成本与完整交易轮次统计；自动 P1 策略模拟应使用 P0 事件证据另行实现。
