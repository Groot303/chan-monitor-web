# Apple Design 全面重构

日期：2026-10-22。用户认为上一版改动太小，要求仅使用第一个Apple Design skill彻底重做。

设计来源仅为 [apple-design/SKILL.md](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md)。没有沿用Taste的方向、抽样脚本或验收规则，也未安装其他设计依赖。业务数据、通知链路及五个页面继续使用原系统。

## 最终设计

- 视觉层：以 `apple-design.css` 替换并移除旧 `mobile-design.css`；保留基础样式中的图表、布局和业务组件结构，新文件统一全部页面。新访客默认浅色；已有用户的深浅偏好继续生效。浅色是系统灰底、白色分组、蓝色操作；深色是黑底与独立的表面明度，非简单反色。
- 导航：手机为浮动底部五项导航与半透明工具栏；桌面为224px侧栏，五个目的地具有同一套图标及文字。保留功能标题，口号、装饰编号继续不显示。
- 信号：三项真实概览、面板外搜索、常用分段筛选、分组信息行。标的、价格、类型、周期、确认状态、分数、时间、K线距离、共振、过期和重绘说明全部保留。表格模式继续可用，持久化键不变。
- 标的：周期方向四栏、最新信号和评分两列，手机单列分组，中文名与交易代码独立。
- 持仓：从API已有字段计算组合摘要，然后是完整持仓明细、组合图和单标的图。不混加不同币种，不把缺失值填零；汇总逐行显示到分的金额。
- 宏观：五个原有主题各自分组，真实指标、传导画布、公布解读、资产矩阵、环境评估及术语入口全部保留。
- 详情：独立阅读空间、手机返回按钮、头部减少重复信息、信号价突出、原评分解读和图表保持可用。

## Apple原则的具体落点

| 原则 | 实现 |
| --- | --- |
| 按下即反馈 | CSS `:active`，不等待click提交才响应 |
| 直接操纵 | 面板抓手Pointer Events和pointer capture；位置按指针位移1:1更新 |
| 可中断 | 每个面板独立状态；动画从当前屏幕位置与速度继续，关闭中途重开不跳回起点 |
| 弹簧与速度交接 | 临界阻尼解析解，omega28；松手速度传入弹簧，使用指数衰减位置投射判断关闭 |
| 软边界 | 负向越界使用非线性阻尼，反向拖动取消关闭 |
| 空间一致性 | 手机详情从右侧进入并向右退出；底部面板沿同一路径开合 |
| 材质层级 | 工具栏、导航和遮罩有半透明层；文字与数据分组保持实色 |
| 可读与系统适配 | 系统字体、分尺寸字距与行高、等宽数值、16px手机搜索框 |
| 用户偏好 | 独立支持减少动态、减少透明度、高对比；键盘打开即时呈现 |
| 状态可靠 | 焦点循环、关闭后返回入口、背景滚动锁、旋转清理旧坐标 |

不模拟交易、支付或注册，不改变评分与信号算法，不修改Telegram配置及推送规则。
