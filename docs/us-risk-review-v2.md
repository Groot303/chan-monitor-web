# 美股自动模拟 V2：风险定仓、组合限制、分类复盘

用户确认继续实施优化路线图前三项。V2独立账户 `us-daily-30m-v2-risk`，初始100,000 USD，从真实启动后的新信号开始。V1仍以原策略ID、原资金和持仓继续运行；不迁移、清空或重算旧记录。默认手机观察页展示V2，可只读切换V1。

## 风险定仓

保留已完成日线up、已知非熊SPY、确认30分钟2B/3B入场、经典1S/2S/3S或止损退出，不改检测器和评分。原信号极值下方 `STOP_PCT`（目前3%）止损不变。

- 单笔风险上限为当前**已知净资产的0.5%**；预算向下取整至分，不用最初10万美元长期固定计算。
- 预期入场价计买入5bp滑点，预期止损卖价计卖出5bp滑点，预算损失包含双边费用；按整股二分求最大数量。
- 仍受单笔初始资金10%的资金预算、现金预留和最多5个标的约束。因此风险额度充裕时也不会自动扩大为大额集中仓位。
- 没有完整同步持仓报价、入场或止损证据时，拒绝新买入；卖出及既有止损继续，不受此限制。
- 决策保存 `risk_plan`：净资产、单笔/组合上限、已占风险、冻结预算、预期入场与损失、人工风险分组版本。待成交买单保留全部冻结风险额度。
- 撮合开盘时只使用冻结证据、该根open与已声明滑点/费用复核；若风险或资金预算超限则拒绝整单，不用未来报价回看，不事后缩量凑结果。V1及手动订单不启用此新限制。

图示的“500÷5=100股”是忽略成本的解释例子；实际数量还需扣除费用/滑点和资金限制，不承诺恰好100股。

## 组合限制

组合计划止损风险不高于决策时已知净资产的2%，含持仓和待成交买单。持仓按当前参考价与实际入场价的较高者到保护价的保守损失估计，避免价格下跌时释放原始风险后继续加仓。剩余预算小于单笔预算时进一步缩减股数。存在缺失或已触发的止损保护时不新增风险。

风险组使用显式人工映射 `manual-risk-groups-v1`：

| 组 | 标的 | 上限 |
| --- | --- | --- |
| 半导体 | NVDA、AMD、AVGO、INTC、MU、TSM、MRVL、SNDK、SKHY | 2只 |
| AI硬件 | LITE、AAOI | 2只 |
| 平台与软件 | META、GOOG、ORCL、PLTR | 2只 |
| 消费电子 | AAPL | 2只 |
| 通信 | NOK | 2只 |
| 出行 | TSLA | 2只 |
| 生物科技 | MRNA | 2只 |
| 科技成长交叉组 | 上述除MRNA外的已列标的 | 3只 |

同一股票计入细分组及交叉组；按标的数统计，待成交买单也占位。这是用于模拟的人工风险分组，不是标准行业认证或实测相关系数。SPCX及未来新标的没有经核验映射时跳过V2买入，不默认为“其他”；V1保持原范围。

0.5%和2%均为**计划风险参数**，不是最大实际亏损保证。其他持仓价格、净资产和跳空随后可能使风险超过下单时门槛；止损成交根内先后、入场第一根无止损和OHLC延迟等V1模型假设仍存在。本次不改逐笔成交真实性、追价过滤或退出数学。

## 分类复盘与兼容

新成交事件追加真实lot_id、卖出FIFO成本分摊、实际入场信号类型、初始止损与计划风险；旧字段、现金计算和费用不变。事件仍不可更新或删除，旧数据不追溯修改。

- 按二买/三买、最终退出原因汇总完整交易数、胜率、平均R和持有时间；一个买入批次分多次卖出，全部退出后才计一笔完整交易。多种卖出原因标为mixed。
- `R = 全部退出后扣费实际盈亏 ÷ 实际入场时的计划风险`。初始风险由实际成交价、止损与成本计算，不把“500美元上限”直接充当每笔风险。
- 实现盈亏包括已部分退出的成本分摊；胜率、平均R、平均持有时间只统计全部平仓样本，两种口径在页面解释。
- 每次后台检查只追加实际看到的持仓估值点，同一lot/行情时间第一次记录后不覆盖；退出价来自不可变成交事件。展示“已观察浮亏/浮盈”，**不宣称为全部盘中MAE/MFE**；估值缺失时留空，不借未来修订价格重建有利历史。
- V1已存在的旧成交没有lot关联/风险字段时，保留总资金、成交、盈亏，明确计入“旧数据缺少关联证据”，不伪造完整交易、R或历史极值。

`GET /api/strategy/us`仍返回V1以兼容旧调用；`?version=v2`返回固定V2；仅允许v1/v2，不接受任意账户ID，无写入路由。两个版本共享行情读取缓存，各自事务和基线独立；单个版本异常不会阻止另一个版本轮询。原后台账本继续撮合两账户的待成交单及止损。

页面只读切换版本。公平比较只使用V2创建后两个账户**同一时刻**的共同估值点，从首个共同点各自归一化；不足两个点就等待，不直接比较不同启动时刻的累计收益。

新增案例覆盖风险含成本取整、净资产变化、风险/资金跳空拒单且不读取未来报价、冻结证据缺失、同组/交叉组/待成交占位、行情与保护未知、撤单释放预算、版本隔离、异常隔离、完整及部分退出R/现金分摊、止损分类、旧数据unknown和共同估值窗口。浏览器覆盖V1/V2切换、风险说明、复盘展示、只读请求及手机/两主题布局。

这些测试验证实现和账务，不是收益验证。下一阶段独立比较入场距离/盈亏比、方向过滤、退出、执行细节和公司行动，不能在V2内部悄悄修改参数后混合旧收益。
